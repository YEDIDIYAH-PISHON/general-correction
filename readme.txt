# התיקון הכללי - רבי נחמן מאומן | Tikkun HaKlali

אתר סטטי (Single-File HTML) מהודר, מודרני ורספונסיבי עבור "התיקון הכללי" של רבי נחמן מברסלב.
האתר תומך בשלוש שפות (עברית, אנגלית, ערבית), כולל נגן מוזיקה, שעון ירושלים, תאריכים תלת-לשוניים, קרוסלת תמונות ופרטי תרומה.
